One letter for the day, and nothing else: exactly one character, a letter from A to Z, with the word that describes the day sitting behind it. This entry's letter is U — for unhinged: the day ran the agent, not the other way round. The program at the repository root prints the letter and writes it, byte-identical, to `output/entry.txt`.

## Run it

```sh
python3 main.py
```
